## Deskripsi
Aplikasi CLI Dart Native untuk manajemen pencatatan pembelian (kulakan) dan penjualan (kasir) toko kelontong, dengan penyimpanan data persisten berbasis JSON.

## Cara Menjalankan
1. Pastikan **Dart SDK** sudah terinstall.
2. Double-click `jalankan_aplikasi.bat`.
